Despre Aplicație

Ce este Z-FLOW?

Z-FLOW este o aplicație web progresivă (PWA) românească, construită pentru IMM-uri, care centralizează managementul financiar și logistic al companiei — de la emitere și urmărire facturi, la gestiunea flotei și comenzilor de transport. Funcționează complet offline și se sincronizează automat cu baza de date cloud la reconectare.

💼
Gestionare Clienți & Furnizori

Evidența completă a relațiilor comerciale: sold, facturi restante, profil firmă, autofill ANAF prin CUI, badge dual client+furnizor.

📊
Analiză BI în Timp Real

Tablou de bord cu KPI-uri live, cashflow net corect (încasat minus plătit), proiecții, badge scadențe pulsant și export rapoarte PDF/Excel/CSV/XML.

🚚
Logistică & Transport

Comenzi transport, gestionare flotă vehicule, evidență șoferi, rapoarte km vs. livrări și tracking cod cu hartă GPS.

📦
Depozit & Scanner QR

Intrări/ieșiri stoc, scanner cod de bare/QR, asociere automată produs sau comandă de transport, recepții și livrări.

📱
PWA — Funcționează Offline

🏛️

Versiunile 72.x — 73.0

Funcționalități noi & fix-uri majore

Versiunile 72–73 aduc îmbunătățiri substanțiale de UX, securitate, calcule financiare corecte și experiență PWA nativă.

📥
Import Smart Unificat

Un singur buton de import acceptă CSV, Excel și XML. Detecție automată tip (clienți/furnizori/contribuții/XML ANAF UBL 2.1) — fără selecție manuală.

📊
Cashflow Net Corect

Formula KPI Home corectată: Net = Încasat efectiv − Plătit efectiv. Contribuțiile neachitate nu mai distorsionează cashflow-ul — sunt obligații viitoare, nu plăți efectuate.

🔴
Badge Scadență Pulsant BI

Facturile cu scadența depășită au bullet roșu pulsant + text roșu. Scadențele iminente (≤5 zile) au indicatori amber. Identic cu comportamentul de la furnizori.

🏛️
Contribuții Buget Stat

Modul complet pentru TVA, CAS, CASS, Impozit și Altele. Import CSV, filtrare tip și status, integrare opțională în Analiza BI prin checkbox dedicat.

📱
Back Button PWA Nativ

Butonul Back de pe Android funcționează nativ: fiecare tab adaugă un state în history. Double-back pe Home afișează toast + ieșire din app.

⌨️
Scurtături Tastatură

Alt+H (Home), Alt+F (Financiar), Alt+A (Analiză BI) adăugate alăturat celor existente Alt+N, Alt+K, Alt+D, Alt+E. Navigare rapidă fără mouse.

🔑
Token Abonament Robust

Planul (Trial 30 zile / Standard / Pro / Enterprise) se aplică la primul login chiar dacă email-ul necesita confirmare. La eroare de rețea se reîncarcă automat la login următor.

🛡️
Securitate Contribuții

updateContributie() și deleteContributie() filtrează acum corect cu .eq('user_id', uid) — consistent cu toate celelalte operații din aplicație.

🔧
Mod Mentenanță Corectat

Când adminul activează mentenanța, utilizatorii Supabase înregistrați (conturi plătite) văd aplicația în continuare fără overlay. Overlay-ul apare doar pentru demo și vizitatori neautentificați.

🔔
Confirmări PWA-Friendly

Dialogurile de confirmare (ștergere contribuție, marcare bulk încasat) folosesc showConfirmModal() în locul confirm() nativ blocant — UX neted pe mobil.

👤
Profil Firmă Actualizat

Modalul de profil firmă reîncarcă datele proaspete din Supabase la fiecare deschidere — elimină situația câmpurilor goale după modificări recente.

📅
Alertă Scadențe pe Home

Butonul "Vezi toate scadențele →" apare sub lista de alerte Home doar când există scadențe depășite — navigare directă la Financiar cu 1 tap.

Securitate & Administrare

Roluri, permisiuni & administrare

Sistemul de permisiuni granulare asigură că fiecare utilizator vede și poate acționa doar ce îi este permis. Adminul are unelte complete de gestionare a conturilor.

🔴 Administrator local

Acces complet: creare, editare, ștergere date demo, gestionare utilizatori Supabase, generare tokeni abonament, mod mentenanță, dashboard utilizatori cu statistici și extindere abonament.

🟡 Utilizator Supabase înregistrat

Poate crea și edita facturi, clienți, furnizori, comenzi, contribuții. Datele sunt izolate complet prin Row Level Security — nu poate vedea datele altor utilizatori.

🔵 Demo user

Acces demo cu date volatile (se pierd la refresh). Util pentru prezentări. Vede overlay de mentenanță când aceasta este activată de admin.

🟢 Izolare date completă

Admin local → localStorage. Utilizatori Supabase → DB cu filtru user_id + RLS activ pe toate tabelele. Zero posibilitate de acces încrucișat între conturi.

🟣 Token abonament

Fiecare cont nou necesită cod de activare (Trial 30 zile / Standard 365 / Pro / Enterprise). Planul se aplică automat la confirmare email, robust la erori de rețea.

🔷 Mod mentenanță

Adminul poate activa mentenanța cu sincronizare Supabase. Utilizatorii înregistrați continuă să lucreze fără întrerupere. Overlay-ul apare doar pentru demo și vizitatori.
