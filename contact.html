Întrebări frecvente

FAQ — Răspunsuri rapide

Cele mai comune întrebări despre funcționalitățile Z-FLOW, organizate pe teme. Nu găsești răspunsul? Scrie-ne la contact@z-flow.ro.

Ce este Z-FLOW și cu ce diferă față de SmartBill sau Oblio? General
Z-FLOW este o aplicație de suport și vizualizare business, nu un program de facturare. Nu emite facturi în mod direct — importă datele din SAGA, WinMentor sau XML ANAF și le afișează într-un dashboard unificat.

Diferența esențială față de SmartBill/Oblio: Z-FLOW adaugă modulul de logistică complet (comenzi transport, șoferi, vehicule, GPS SafeFleet), scanner QR și funcționare offline completă — funcționalități pe care niciun competitor din România nu le oferă.

Utilizare tipică: folosești SAGA pentru contabilitate + Z-FLOW pentru tabloul de bord zilnic pe telefon.
Z-FLOW funcționează fără internet? PWA
Da. Z-FLOW este o Progressive Web App (PWA) cu Service Worker activ. Toate datele sunt cache-uite local (IndexedDB + localStorage), iar aplicația funcționează complet offline.

Când reconectezi internetul, datele se sincronizează automat cu baza de date Supabase. Bannerul „Fără conexiune la internet" te anunță vizual când ești offline, dar poți continua să lucrezi.
Cum instalez Z-FLOW pe telefon? PWA
Nu ai nevoie de App Store sau Play Store. Deschide aplicația în browser (Chrome pe Android, Safari pe iOS) și:

Android (Chrome): Meniu (⋮) → „Adaugă pe ecranul principal" → Instalare
iOS (Safari): Butonul Share (□↑) → „Adaugă pe ecran principal"

După instalare, Z-FLOW apare ca orice aplicație nativă — fără browser, full-screen, cu back button Android funcțional.
Cum import facturile din SAGA sau WinMentor? Financiar
Folosești butonul „Import SAGA / WinMentor" din meniul FAB (butonul albastru din dreapta jos). Z-FLOW acceptă:

• CSV — export din SAGA (clienți sau furnizori)
• Excel (.xlsx) — export din orice program contabil
• XML ANAF (UBL 2.1) — e-Facturi primite din SPV

Detectare automată tip: Z-FLOW identifică singur dacă fișierul conține clienți, furnizori sau contribuții — nu trebuie să selectezi manual. Importul adaugă doar facturile noi (duplicatele sunt ignorate automat).
Ce este Cashflow Net și cum se calculează? Financiar
Cashflow Net 30 zile = Suma facturilor clienților încasate efectiv în ultimele 30 zile − Suma facturilor furnizorilor plătite efectiv în ultimele 30 zile.

Important: Contribuțiile buget stat (TVA, CAS etc.) nu sunt scăzute din Cashflow Net — ele reprezintă obligații viitoare, nu plăți efectuate. Le găsești separat în cardul „Contribuții Buget Stat".

Widgetul „Estimat luna viitoare" de pe Home calculează proiecția pe baza scadențelor existente.
Ce sunt Contribuțiile Buget Stat și cum le gestionez? Fiscal
Modulul Contribuții (din tab-ul Financiar) îți permite să urmărești obligațiile bugetare: TVA, CAS (pensie), CASS (sănătate), Impozit venit/profit și Altele.

Poți adăuga manual fiecare contribuție cu data scadenței (ziua 25 a lunii), suma și statusul (achitat/neachitat). Poți importa și din CSV. Contribuțiile neachitate apar în alertele de pe Home.

Atenție 2026: TVA a crescut la 21% (din august 2025), iar plafonul microîntreprindere scade la 100.000€. Actualizează sumele contribuțiilor lunar.
Care este cota TVA implicită și cum o schimb? Financiar · TVA
Legea TVA 2025 (Legea nr. 353/2025) aduce două cote unice:

• 21% — Cotă standard — se aplică majorității produselor și serviciilor, inclusiv semnătură electronică. Înflocuiește vechea cotă de 19%.
• 11% — Cotă redusă unificată — înlocuiește fostele 5% și 9%. Se aplică strict: alimente de bază (fără adaosuri de zahăr), produse agricole naturale, medicamente de uz uman, servicii HoReCa, lemn de foc și combustibil solid pentru încălzire, energie termică pentru populație, apă potabilă și canalizare, manuale școlare, cărți, ziare, reviste.
• 0% — Scutit cu drept de deducere / Export

Configurează din: Profil Firmă → Plătitor TVA (ON) → Cotă TVA implicită. Cota se aplică automat la fiecare factură nouă, dar poate fi modificată individual per factură.
Cum trimit facturile la ANAF (e-Factura)? Fiscal · e-Factura
Z-FLOW nu transmite direct în SPV/ANAF — aceasta este responsabilitatea programului tău de contabilitate (SAGA, SmartBill etc.).

Ce face Z-FLOW în relație cu ANAF:
• Import XML UBL 2.1 — importă e-Facturile primite din SPV
• Export Bridge XML — generează fișier XML compatibil SAGA/WinMentor pentru contabil
• Verificare e-Factura — validează dacă un CUI este înscris în sistemul RO e-Factura

Fluxul recomandat: emite în SAGA → exportă CSV → importă în Z-FLOW pentru vizualizare.
Cum conectez SafeFleet sau alt sistem GPS? Logistică
Din tab-ul Logistică → SafeFleet / Nexus → Config, introduci URL-ul webhook și API Key-ul primit de la furnizorul GPS.

Z-FLOW suportă:
• SafeFleet — autentificare API key, preluare locație vehicule
• Nexus — configurare similară
• GPS Generic — orice furnizor care poate trimite webhook JSON cu format standard (latitudine, longitudine, ID vehicul)

Dacă nu ai SafeFleet, harta afișează vehiculele din comenzile active în modul „Simulat".
Scanner-ul QR funcționează pe orice telefon? Depozit
Scannerul folosește Html5-QRCode — o bibliotecă open-source care accesează camera telefonului direct din browser, fără instalare de aplicații.

Compatibilitate: Chrome (Android), Safari (iOS 14+), Firefox (Android). La prima utilizare, browserul cere permisiunea pentru cameră — acordă accesul.

Suportă: QR Code, Code 128, EAN-13, EAN-8, Code 39 și alte formate standard. Scannerul se găsește în Depozit → Scanner SKU / QR.
Datele mele sunt în siguranță? Pot vedea alți utilizatori datele mele? Securitate
Nu. Z-FLOW folosește Row Level Security (RLS) în PostgreSQL (Supabase) — fiecare utilizator vede strict datele proprii. Nu există nicio posibilitate tehnică de acces încrucișat între conturi.

• Autentificare prin JWT (Supabase Auth) — token securizat, expiră automat
• Fiecare înregistrare din baza de date are câmpul user_id legat de contul tău
• Backup automat în infrastructura Supabase (hosted pe AWS)
• Header Content-Security-Policy activ pentru protecție XSS
Cum funcționează planurile de abonament și token-ul de activare? Cont & Abonament
Contul Z-FLOW necesită un cod de activare (token) primit de la echipa Z-FLOW. Planurile disponibile:

• Trial — 30 zile: acces complet, ideal pentru testare
• Standard — 365 zile: toate funcționalitățile incluse
• Pro — 365 zile: funcționalități avansate
• Enterprise: soluție personalizată pentru firme mari

La înregistrare, introduci emailul, parola și codul token. Planul se activează automat. Contactează-ne la contact@z-flow.ro pentru a obține un cod.
Cum activez notificările pentru facturi scadente? Notificări Push
Din Profilul Firmei → Notificări Scadențe → Activează Push, browserul îți va cere permisiunea pentru notificări.

Odată acordată, Z-FLOW îți va trimite notificări browser/PWA pentru:
• Facturi clienți cu scadența depășită sau iminentă (≤5 zile)
• Contribuții buget stat neachitate cu scadența pe 25 ale lunii
• Facturi furnizori cu scadența depășită

Notă: Notificările funcționează chiar și când aplicația este minimizată, dacă Z-FLOW este instalat ca PWA pe dispozitiv.
